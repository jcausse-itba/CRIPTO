## 3. Core Architecture & Implementation Decisions

### 3.1. Bitmap Carrier (`include/bitmap.h`, `src/bitmap.c`)
- **Complete In-Memory Dump:** Reads headers + pixels + row padding into a contiguous `malloc`'d buffer (`uint8_t * data`), enabling $O(1)$ indexing and single `fwrite` on `bitmap_save`.
- **BMP V3 Validation:** Enforces `'BM'` (`0x4D42`), `biSize == 40`, `biPlanes == 1`, `biBitCount == 24`, `biCompression == 0` (`BI_RGB`), `biWidth > 0`, `biHeight != 0`, and `bfOffBits >= 54`. Note BMP rows are stored **bottom-up** (`biHeight > 0`) with physical channel order **`B, G, R`**.
- **Public API Extensions Added for LSBI:**
  - `bool bitmap_has_padding(bitmap b)`: returns `true` when `stride > row_bytes` (`(width * 3) % 4 != 0`).
  - `bool bitmap_get_byte_at(bitmap b, size_t index, uint8_t * out_byte)`: non-mutating random-access byte read without advancing `b->cursor`.

### 3.2. Steganography Payload Wire Format (`src/embed.c`, `src/extract.c`)
1. **Unencrypted:** `[4B Big-Endian real_file_size] || [file_data] || [.ext\0]` (`total = 4 + file_size + strlen(ext) + 1`).
2. **Encrypted:** Encrypt `[4B BE real_file_size || file_data || .ext\0]` with OpenSSL (PKCS#5/PKCS#7 padding), then embed `[4B Big-Endian ciphertext_len] || [ciphertext]`.
3. **Endianness:** Portable shifts (`write_be32` / `read_be32`) instead of POSIX `htonl`/`ntohl`.

### 3.3. CLI & Cryptography (`src/cli_arguments.c`, `src/cryptography.c`)
- **Validation & Defaults:**
  - `-pass` absent $\rightarrow$ no encryption; `-a` or `-m` without `-pass` $\rightarrow$ error; empty `-pass ""` $\rightarrow$ rejected (`password_not_empty` validation in `src/cli_arguments.c`).
  - `-pass` alone defaults to `AES128` + `CBC`.
- **OpenSSL Parameters:** `PKCS5_PBKDF2_HMAC` with `SHA-256`, `10,000` iterations, fixed 8-byte zero salt (`{0}`), extracting `key || iv`. Supports `aes128`, `aes192`, `aes256`, `3des` (`EVP_des_ede3_*`) in `ecb`, `cfb` (`cfb8`), `ofb` (128-bit), `cbc`.

### 3.4. Steganography Strategies (`src/steganography.c`)
- **LSB1:** 1 bit per byte (MSB-to-LSB of each secret byte), contiguous over pixels + padding. Capacity: `carrier_bytes / 8`.
- **LSB4:** 4 bits per byte (high nibble first, low nibble second), contiguous over pixels + padding. Capacity: `carrier_bytes / 2`.
- **LSBI (Majeed & Sulaiman + `doc/LSBI_Implementation_Notes.md` Consensus):**
  1. **Control Map (First 4 Bytes):** Indices `0..3` (`B0, G0, R0, B1`) store the 4 inversion flags for patterns `'00'`, `'01'`, `'10'`, `'11'` using standard `LSB1` (all 3 channels used, never inverted).
  2. **Selective Channels (Index $\ge 4$):** Starting at `G1`, **Red channel bytes (`offset % 3 == 2`) are skipped** via `lsbi_next_carrier_byte` / `lsbi_get_carrier_byte`. Only Blue and Green carry payload bits.
  3. **Row Padding Design Decision (Agreed with Cátedra):** **LSBI does NOT support/process BMPs with row padding** (`(width * 3) % 4 == 0` is assumed), because padding bytes desynchronize the periodic `(B, G, R)` channel skipping across rows. `embed_main` and `extract_main` log a `LOG_WARN` if `steg_alg == STEGO_ALG_LSBI && bitmap_has_padding(bmp)`.
  4. **Inversion & Efficiency:** Pass 1 embeds via LSB1 while counting `changed[p]` vs `unchanged[p]` for `pattern = (*carrier >> 1) & 0x03U`. If `changed[p] > unchanged[p]`, `inv_mask[p] = 1`. Pass 2 flips LSBs via branchless XOR and **is omitted entirely if `!any_inverted`**. Extraction (`lsbi_extract_bytes`) is **single-pass and stateless** (reads header bits `0..3` into a local `uint8_t invert[4]` array via `bitmap_get_byte_at`, then applies `(carrier & 0x01U) ^ invert[pattern]` without branches).
  5. **Capacity:** `rem = carrier_bytes - 4`; `skipped_red = (rem + 1) / 3`; `max_capacity = (rem - skipped_red) / 8`.

## 6. Past Bugs Solved & Gotchas to Avoid

1. **`fileno` under `-std=c23 -pedantic` (`lib/logger.c`):** Needs `#define _POSIX_C_SOURCE 200809L` before `<stdio.h>`.
2. **GCC 15 `-Werror=unterminated-string-initialization` (`test/cryptography_test.c`):** Use unsized `const uint8_t data[] = "...";`.
3. **`inline` without body in headers:** Keep internal helpers `static` in `.c` files.
4. **Big-Endian sizes:** Always serialize/deserialize 32-bit payload lengths via `write_be32` / `read_be32`.
5. **Pillow 12.1.1 `Image.Resampling.NEAREST` crash:** Use `BOX`/`BILINEAR`/`LANCZOS` or 1:1 crops.
